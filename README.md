svolky-tool by svolky
Outil graphique tout-en-un distribué en exécutable unique (.exe). Interface Matrix par défaut, fond d'écran personnalisable, mode plein écran sans bordures.

Fonctionnalités
Searcher
DDoS : Attaque TCP sur IP et port définis

IP Grabber : Serveur HTTP local pour capturer les adresses IP

IP Localiser : Géolocalisation d'une adresse IP (pays, ville, FAI...)

Discord
Nitro Generator : Génère 10 codes Nitro aléatoires

Webhook Spammer : Envoi massif de messages via URL de webhook

Server Nuker : Suppression de tous les salons et rôles d'un serveur (token bot requis)

Spam DM : Envoi de messages privés en boucle à un utilisateur

Roblox
Carte Generator : Génération de codes-cadeaux Roblox factices

Cookie Grabber : Extraction du cookie .ROBLOSECURITY depuis les fichiers locaux de Roblox

Gamepass Free : Obtention gratuite d'un gamepass en exploitant l'API Roblox avec le cookie récupéré

Apparence
Fond d'écran personnalisable (image PNG/JPG)

Mode plein écran sans bordures (Échap pour quitter)

Sélecteur de couleur du thème

Thèmes prédéfinis : Matrix, Cyberpunk, Océan, Minimal

Utilisation
Télécharger l'archive

Lancer svolky-tool.exe
Aucune installation supplémentaire requise.
